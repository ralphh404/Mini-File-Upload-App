# Mini File Upload App

A simple web application built as a personal learning project to explore web development, backend programming, and cloud-based file storage.

**[Live Demo](https://mini-file-upload-app-dbnm.onrender.com/)** · **[GitHub Repository](https://github.com/ralphh404/Mini-File-Upload-App)**

## About the Project

This project started as a simple mini file upload app, but it gradually grew as I experimented with my own ideas and challenged myself to learn more about web development.

Instead of stopping at basic file uploading, I added features such as folder management, file organization, and other improvements to make the application more useful.

The project gave me practical experience working with both the frontend and backend, integrating Cloudinary for file storage, and deploying a web application using Render.

This is a personal learning project that I built to improve my skills and explore how the different parts of a web application work together.

## Features

- **File Uploading** — Upload files through the web interface.
- **Folder Management** — Organize uploaded files into folders.
- **Folder Search** — Search for folders by name.
- **File Previews** — Preview supported files through the application.
- **File Renaming** — Rename uploaded files.
- **File Deletion** — Remove files when they are no longer needed.
- **File Sorting** — Organize files using the available sorting options.
- **Cloud Storage** — Integrate Cloudinary for file storage.
- **Backend Processing** — Handle application operations through an Express.js backend.

## Technologies Used

- **HTML** — Page structure
- **CSS** — Styling and layout
- **JavaScript** — Frontend functionality and application logic
- **Node.js** — JavaScript runtime for the backend
- **Express.js** — Backend web framework
- **Cloudinary** — Cloud-based file storage
- **JSON** — Data storage for application configuration and folder information
- **Render** — Application deployment
- **Git and GitHub** — Version control and source code management

## What I Learned

Building this project helped me gain practical experience with:

- Understanding how the frontend communicates with the backend.
- Building and structuring a backend using Express.js.
- Integrating third-party services such as Cloudinary.
- Working with APIs and asynchronous JavaScript.
- Debugging issues and improving existing features without losing sight of the overall application.
- Turning my own ideas into functional features.
- Managing environment variables and protecting sensitive credentials.

One of the biggest challenges was starting from scratch and understanding how the frontend and backend communicate. Working through that challenge helped me better understand how a web application operates beyond what users see on the screen.

## Project Status

The core features of this app are complete:

- File uploads with type and size restrictions (images, PDFs, text, and Office files, up to 10 MB each)
- Folders for organizing files
- Search and sorting by name, size, or date
- Rename and delete
- Image and document previews
- Global limits of 15 files and 5 folders

I'm not adding more features to this version.

This app is intentionally open so anyone can try it as a public demo. That's why there's no login, and why the file and folder limits are shared by all visitors.
